# Facet AI

## Stack
Next.js 16 App Router, React 18, Supabase (Auth, Postgres, Storage), Groq vision, Stripe.

## Build
```sh
npm ci
npm run dev
npm run build
npm start
```

## Functionality
- Signed front and side photo uploads to private Supabase Storage with AI-generated feedback.
- Feature scores, improvement plans, scan history, and coaching.
- Supabase authentication, profiles, and private photo storage.
- Stripe subscriptions and billing webhooks.
